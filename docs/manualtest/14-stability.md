# 14. Stability

- **Status:** To do
- **Area:** Longer runs
- **Why it's manual:** Hours of real use (spec §8, §13).
- **Needs:** Your AVD account (as a normal user) and a desktop to connect to.

## Steps

1. Use a desktop for a few hours, including idle time.
2. Change audio devices during it.
3. Plug in a monitor.
4. Let the computer sleep and wake it.

## Expected

- Nothing crashes or hangs; the desktop keeps working or reconnects. Note anything odd, with the time, so it can be found in the log.
