# 4. Start when you log in

- **Status:** To do
- **Area:** Background and tray
- **Why it's manual:** Needs COSMIC's real autostart.
- **Needs:** Nothing special.
- **Background:** [ADR 0017](../adr/0017-background-operation-and-tray.md)

## Steps

1. Turn on Settings → Background → Start when you log in.
2. Log out of COSMIC and back in.

## Expected

- Only the tray icon appears, no window.
