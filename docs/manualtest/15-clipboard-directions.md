# 15. Clipboard directions

- **Status:** To do

## Steps

1. Set Clipboard to "Only to the desktop" and reconnect.
2. Copy text here and paste it in the desktop.
3. Copy text in the desktop and paste it here.
4. Optionally turn on "Copy files" and copy a file in.

- With Copy files: the file arrives in the desktop.
