# Research scripts (retired)

These scripts were used on 2026-10-17 during the milestone 1 investigation. They are **not needed to build, test or use the app**, and you don't need to run them.

Since [ADR 0006](../docs/adr/0006-build-app-alongside-compatibility-work.md), open questions are answered with the app itself. The terminal sign-in step in `password-login-test.sh` no longer works because Microsoft blocks copying the `nativeclient` URL (see `docs/milestone-1.md`).

Automated tests run with `cargo test` and need no account.
